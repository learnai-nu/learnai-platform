# Blue Orbit prototype

Isoleret, klikbar designprototype til LearnAI.nu. Den ændrer ingen eksisterende Astro-ruter, layouts eller produktionsstyles.

## Åbn prototypen

Åbn `index.html` direkte i en browser, eller servér mappen med en valgfri lokal statisk server.

Prototypen indeholder:

- responsiv forside og mobilnavigation
- interaktive kursusfiltre
- kursusdetalje og lektionsafspiller
- faner for dashboard, admin og Lær AI-bibliotek
- lyst og dybt blåt tema
- reduceret bevægelse via `prefers-reduced-motion`
- tastaturfokus, semantiske landmarks og labels

## Afgrænsning

Dette er et designstudie med statiske eksempeldata. Links, formularer og handlinger illustrerer produktadfærd, men er ikke forbundet til Supabase.
