# Grok Bot

**Kort beskrivelse:** AI-agenter, der arbejder i dine apps og på websites

**Beskrivelse:** Grok Bot lader dig give research, indholdsarbejde og andre opgaver med flere trin til AI-agenter. De bruger en delt computer i skyen med browser, filer og terminal og kan samarbejde om opgaven. Du sætter mål og rammer, følger arbejdet og godkender handlinger med konsekvenser. Begynd med en afgrænset opgave, og kontrollér resultatet. Alle dine Bots deler filer og logins på computeren, så giv kun adgang til det nødvendige.

**Nøglefunktioner:**

- Arbejder på tværs af apps og websites med browser, filer og terminal.
- Flere Bots kan koordinere og fortsætte opgaver, når din egen computer er lukket.
- Kan stoppe for godkendelse og gemme gentagelige arbejdsgange som rutiner.

**Kategorier:** Automatisering, research og kode.

**Pris og adgang:** Kræver en kvalificerende betalt Cursor- eller SuperGrok-plan. Inkluderet forbrug og eventuel betaling for yderligere brug afhænger af planen.
